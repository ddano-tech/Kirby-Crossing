Keyboard: arrows move, X = A, Z = B, Enter = Start, Tab switches games.

Other keyboard buttons: S = X, A = Y, Q/E = L/R, C = Z trigger. I/J/K/L provide D-pad up/left/down/right for menus.

PS5: left stick moves, Circle = A, Cross = B, Options = Start, Create switches games. Connect the controller and press a button to make it visible to the browser.

Square/Triangle = Y/X, L1/R1 = L/R, L2 or R2 = Z, D-pad = game D-pad, right stick = C stick.

Only standard browser gamepad mappings are accepted. Physical PS5 support is awaiting testing. Changing game releases held inputs; pausing, hiding this tab, disconnecting a controller, or losing the bridge connection releases controls.
